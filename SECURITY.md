# Security

This is a local research prototype, bound to 127.0.0.1. Do not expose the development server to the internet. It has no account system or durable multi-user storage. Scenario files may contain operational information; keep them local unless you intend to share them.

Report vulnerabilities through GitHub's private vulnerability reporting when enabled; otherwise contact the maintainer without including exploit secrets in a public issue. No response-time commitment is implied.
